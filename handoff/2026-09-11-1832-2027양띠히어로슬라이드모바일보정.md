## 1. 목표

직전 세션(`2026-09-11-1759`)에서 완성한 2027 양띠 히어로 슬라이드에 대해,
(1) 다른 슬라이드 수준(2400px대)으로 해상도를 올릴지 검토하고, (2) 모바일에서
코인이 과도하게 확대·우측 크롭되어 거의 안 보이는 문제를 해결하고, (3) 앞/뒤
코인 겹침을 줄이는 것.

## 2. 현재 상태

**확인 완료**:
1. **해상도 업스케일 검토 → 미채택**: 기존 1869px 파일을 Lanczos로 2430px까지
   단순 업스케일한 프리뷰와 원본을 동일 배율로 크롭 비교한 결과, 실제 선명도
   차이가 거의 없음을 확인함(사용자도 육안으로 차이를 못 느낀다고 확인).
   이후 고해상도 소스(`images/products/2027/goat.png`, `goat-back.png`,
   1200×1200)에서 배경+코인을 처음부터 재합성한 2430px 버전도 만들어 크롭
   비교했을 때는 실제 선명도 차이가 뚜렷했으나, 일반 열람 크기에서는 체감
   차이가 없다고 판단하여 **해상도 자체는 원본 1869px을 그대로 유지**하기로
   결정함.
2. **모바일 코인 크기/위치 문제 확인 및 수정 완료**: PIL로 `background:
   ... center/cover` 동작을 시뮬레이션한 결과, 390×400px 모바일 화면에서
   기존 설정으로는 코인이 화면을 거의 다 채울 정도로 확대되고 오른쪽으로
   크게 잘려 코인 얼굴 일부만 겨우 보이는 수준이었음(스크린샷으로 확인).
   다른 슬라이드(버팔로 등, 실사 배경+중앙 배치 코인 구도)는 모바일에서 코인이
   화면의 가로 ~70%·세로 ~60% 정도를 차지하며 위아래 여백이 있는 것으로 측정됨.
   goat-2027은 최종적으로 이보다 더 작게(`background-size: 150%`) 축소하고
   `background-position: 89% center`로 왼쪽으로 당겨 반영함.
3. **앞/뒤 코인 겹침 축소 완료**: 기존 최종본은 앞면(양)이 뒷면(찰스 3세)의
   상당 부분을 가리고 있었음. 고해상도 소스에서 재합성하되 해상도는 원본과
   동일한 1869×474px로 유지하면서, 뒷면 코인의 좌측 오프셋을
   `front_h × 0.62` → `front_h × 0.78`로 늘려 겹침을 줄이고 찰스 3세 얼굴이
   더 많이 보이도록 조정함.
4. **최종 이미지를 `images/header-slide-goat-2027.jpg`에 반영, 커밋
   `3b73029`로 push 완료** (`git fetch`로 직전 원격 커밋 `c188824`와 로컬
   일치 확인 후 커밋 → push). `git ls-remote`로 반영 확인함.
5. `index.html`의 슬라이드 렌더링 템플릿에 `data-slug="${s.slug || ''}"`
   속성을 추가해, 슬라이드별로 모바일 CSS를 타겟팅할 수 있게 함.
6. `assets/css/style.css`의 `@media (max-width: 768px)` 블록에
   `.slide[data-slug="goat-2027"] { background-size: 150% auto !important;
   background-position: 89% center !important; }` 규칙을 추가함(인라인
   스타일로 설정된 `center/cover`를 모바일에서만 오버라이드).
7. PAT는 push 직후 plain HTTPS로 원복 완료, `git remote -v`로 확인.

**미확인 (다음 세션 To-Do로 이월)**:

    아크 텍스처(2곳 중심점)
  - 코인 컷아웃: 원본 PNG(1200×1200, 흰 배경)에서 실제 코인 픽셀 bbox를
    감지해 정사각형으로 크롭한 뒤 원형 마스크 적용(패딩을 너무 작게 주면
    흰 테두리가 남으므로 bbox 기준 크롭이 중요)
  - 드롭섀도우: 코인 알파를 블러 처리해 별도 레이어로 합성
  - 앞면 코인 높이 = 프레임 높이 × 1.04, 뒷면 = × 0.96 (상하로 살짝
    베어나가게), 앞면 좌측 시작 = 프레임 폭 × 0.527, 뒷면 좌측 시작 =
    앞면 좌측 + 앞면 높이 × 0.78(이번 세션 조정값, 기존 0.62)
- **모바일 background-size/position 튜닝 방법**: PIL로 CSS의 `cover` /
  `width_pct% auto` 배치 로직을 재현하는 시뮬레이터 함수를 짜서, 실제 브라우저
  없이도 여러 옵션을 빠르게 프리뷰 비교할 수 있었음. 다른 슬라이드에 비슷한
  작업이 필요하면 이번 세션 스크립트 로직 재사용 가능(코드 자체는 미커밋,
  대화 맥락 참고).
