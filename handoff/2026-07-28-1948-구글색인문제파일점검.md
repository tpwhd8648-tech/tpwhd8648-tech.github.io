# 구글 색인 문제 파일 점검 인수인계 문서

작성일: 2026-07-28 (KST)

## 1. 목표

여러 세션째 미해결로 남아있던 🔍 SEO To-Do "구글 서치 콘솔 데이터 확인(색인 수,
미색인 사유)"과 관련해, 이번 세션에서는 사용자가 서치 콘솔 화면을 직접 캡처하기
전에 **파일 레벨(robots.txt, sitemap.xml)에 원인이 있는지부터 선제적으로 점검**함.
결론적으로 파일 자체는 문제 없음을 확인했고, 원인이 서치 콘솔 설정 쪽일 가능성이
높다는 진단까지 정리함. 코드 변경은 없음(점검만 수행).

## 2. 현재 상태

### (1) robots.txt / sitemap.xml 파일 점검 (확인 완료, 코드 변경 없음)

- 로컬 클론 파일과 `raw.githubusercontent.com`의 실제 배포 파일을 diff로 비교 →
  **완전히 동일함** (배포 누락이나 캐시 문제 아님, 확인 완료)
- `robots.txt`: `Allow: /`로 전체 크롤링 허용, `Sitemap:` 라인에 정확한 절대경로
  명시. 문제 없음.
- `sitemap.xml`: Python `xml.etree.ElementTree`로 파싱 시도 → 정상 파싱, 26개
  `<url>` 태그 확인. `od -c`로 파일 앞부분 바이트 직접 확인 → BOM(바이트 순서
  표시, 인코딩 깨짐의 흔한 원인) 없음. UTF-8 인코딩 정상.
- `index.html`: `noindex` 메타 태그 없음, `<link rel="canonical" href="https://tpwhd8648-tech.github.io/">`
  정상 설정 확인.
- 커스텀 도메인(CNAME 파일) 없이 기본 `github.io` 도메인 사용 중이며, sitemap
  안의 모든 URL이 이 도메인과 일치함 (도메인 불일치로 인한 색인 누락 가능성 배제).
- **결론**: 파일 자체는 구글이 못 읽을 이유가 없는 상태. "사이트맵 알 수 없음"
  오류의 원인은 파일이 아니라 서치 콘솔 설정(속성 유형, 사이트맵 제출 방식 등)
  쪽일 가능성이 높음.

### (2) 구글 공식 문서 기준 "알 수 없음" 상태의 의미 (웹서치로 확인)

- 구글 서치 콘솔 공식 도움말: "알 수 없음 = 제출한 파일이 알려진 사이트맵 유형이
  아니거나, 사이트맵이 아직 처리되지 않은 상태"
- 통상 사이트맵 제출 후 정상 케이스라면 2주 이내에 색인이 시작되는 편이며, 그
  이상 지속되면 다른 문제가 있을 확률이 높다는 게 일반적인 SEO 커뮤니티 중론
  (OneTroy는 이미 이 기간을 훌쩍 넘긴 상태로 추정됨).

### (3) 네이버 vs 구글 색인 상태 차이 확인 (검색으로 재검증)

- 웹서치 도구로 "원트로이 불리온" 검색 → 무관한 결과만 나옴 (사이트 전혀 안 잡힘)
- `site:tpwhd8648-tech.github.io` 검색 → 결과 없음
- 반면 사용자는 네이버에서는 검색된다고 확인함 → 두 검색엔진의 크롤링/색인
  메커니즘 차이(네이버는 서치어드바이저 제출 시 반영이 비교적 빠른 편, 구글은
  도메인 신뢰도·백링크 기반으로 크롤 우선순위를 매겨 신규/저권위 도메인인
  `*.github.io` 서브도메인은 크롤링이 뒤로 밀리는 경향)로 설명됨
- 검색 유입이 없는 것과 구글 미색인은 인과관계가 반대일 가능성 — "유입이 없어서
  안 잡힌다"가 아니라 "구글이 아직 제대로 크롤링을 안 해서 유입도 없고 색인도
  안 되는" 상태로 추정 (닭-달걀 관계)
