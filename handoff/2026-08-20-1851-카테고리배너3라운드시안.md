# 카테고리 배너 3라운드 시안 인수인계 문서

작성일: 2026-08-20 18:51 (KST)

## 1. 목표

`index.html` 카테고리 배너(`.cat-gold`/`.cat-silver`/`.cat-collectible`) 배경
톤/패턴을 "무난함" 기준으로 확정하는 작업의 연속. 매 라운드 3개 시안을
만들어 비교하는 기존 합의 방식(`2026-08-20-1703` 참고)에 따라 이번 세션에서
**3라운드(6안/7안/8안)**를 생성·공유했고, 사용자가 6안을 우선 임시 적용하되
**아직 최종 확정은 아니며 다음 세션에서 4라운드로 계속 이어갈 예정**.

## 2. 현재 상태 (확인 완료)

### (1) 이전 상태와의 불일치 발견 (세션 초반)

세션 시작 시 최근 handoff 3개를 확인하던 중, `2026-08-20-1719` 문서는
"2라운드(3/4/5안) 피드백 대기 중, 톤 미확정"이라 기록했지만 **실제
`assets/css/style.css`엔 이미 5안(보케블러, `-bokeh.svg`)이 적용·커밋되어
있었음**. 이 모순을 사용자에게 보고했고, 사용자가 "괜찮은데 조금 아쉬워서
더 비교해보고 싶다"고 답해 3라운드 진행으로 이어짐.

### (2) 3라운드 — 6안/7안/8안 생성 (확인 완료)

`scripts/generate-category-banners.py`(기존 low-poly 생성 스크립트)와는 별개로
새 Python 스크립트로 3개 컨셉 × 3색(gold/silver/bronze) = 9개 SVG 생성:

- **6안 보케 리파인**: 기존 5안(보케블러) 대비 빛망울 개수를 줄이고(12개→6개)
  크기를 키움(반경 20~54→45~80), 투명도도 낮춰(0.1~0.21→0.06~0.13) 더 은은하게
- **7안 길로셰 강화**: 2라운드 4안(길로셰)이 "패턴이 거의 안 보인다"는 자체
  평가가 있었던 것을 반영해 곡선 투명도를 0.12→0.16~0.24로 올리고 선 굵기도
  조정. 화폐/증서 테마와 개념적으로 잘 맞으나, 은화 배경에서는 선이 다소
  두드러져 보일 수 있음
- **8안 새틴 쉰**: 완전히 새로운 컨셉 — 대각선으로 지나가는 은은한 흰색
  하이라이트 밴드 하나만 사용한 미니멀 버전. 패턴이 거의 없어 "무난함"
  기준엔 가장 부합하나, 밋밋하다는 인상을 줄 수도 있음

Playwright로 실제 배너 레이아웃(현재 사이트 크기 기준: 높이 220px, gap 12px,
`.cat-overlay`/`.cat-content` 포함)에 조립한 비교 스크린샷을 만들어 파일로
전달(`카테고리배너_3라운드비교.png`) — **주의: 첫 시도 시 이미지가 대화창에
바로 렌더링되지 않는 문제가 있어, `present_files`로 파일 전달하는 방식으로
전환해 해결함. 다음 세션도 이미지 비교 시 처음부터 파일 전달 방식을 쓸 것.**

## 3. 진행 단계

1. 세션 시작, PROJECT_INSTRUCTIONS.md 및 최근 handoff 3개 확인 → 5안이
   이미 적용된 상태임을 발견해 사용자에게 보고
2. (카테고리 배너와 무관한 작업 먼저 진행: 금시세 배너 이미지 은화 교체,
   문의 배너 이미지 이글코인 뒷면 교체, 버튼 텍스트 수정 — 별도 handoff
   `2026-08-20-1834` 참고)
3. 사용자가 "배경 톤 더 비교해보고 싶다"고 요청 → 3라운드(6/7/8안) 생성
4. 비교 스크린샷을 처음엔 인라인으로 시도했으나 사용자에게 안 보임 →
   `present_files`로 파일 전달해 해결
5. 사용자가 6안 선택, 단 "확정 아님, 다음 세션에 이어서" 조건부로 승인
