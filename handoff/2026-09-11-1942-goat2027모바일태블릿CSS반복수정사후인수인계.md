## 2. 현재 상태

### 확인 완료 (diff로 직접 확인)

직전 핸드오프(`e33af52`, 커밋 `3b73029` 기준) 이후 **자동 생성 커밋을 제외하고**
6개의 커밋이 있었습니다:

1. **`f0586f2`** — 모바일 상하 검은 여백 버그 수정.
   `.slide[data-slug="goat-2027"]`의 `background-size`를 `150% auto` →
   `cover`로 변경(`position: 89% center`는 유지). 커밋 메시지에 따르면
   원본 이미지(1869×474)가 `150% auto` 기준 계산 시 높이가 슬라이더
   높이(400px)보다 작아져 컨테이너 배경색(#111)이 위아래로 노출되는
   문제였다고 기록됨.
2. **`ed652d6`** — goat-2027 이미지(`header-slide-goat-2027.jpg`) 재합성,
   앞/뒤 코인 지름을 프레임 높이 대비 104%/96% → 56%/50%로 축소(파일
   크기 186,669 → 99,496 bytes). 코드 diff 없이 이미지 바이너리만 교체됨.
3. **`fa88bb1`** — 코인 크기를 다시 70%H/62%H로 확대하고, 배치를 이미지
   정중앙 부근으로 이동(이미지 재합성, 99,496 → 113,360 bytes). 이 변경으로
   goat-2027 전용 모바일 CSS 오버라이드가 불필요해졌다고 보고 **삭제**
   (기본 `center/cover`만 사용하도록 되돌림).
4. **`fd8beb1`** — 태블릿(769~1024px) 구간에 코인 위치를 오른쪽으로 이동하는
   규칙 추가, 모바일 레이아웃을 텍스트 상단/코인 하단으로 분리하는 규칙
   추가, `index.html`의 슬라이드 제목을 `'2027 양띠<br>골드 코인'` →
   `'Year of the Goat'`로 영문화.
5. **`f658a6b`** — 바로 위 `fd8beb1`을 `git revert`로 **전체 되돌림**
   (태블릿 위치 규칙, 모바일 분리 레이아웃, 영문 제목 모두 원복). 커밋
   메시지에는 되돌린 이유가 기록되어 있지 않음.
6. **`1e856b9`** — 되돌린 직후, 비슷한 방향이지만 다른 구현으로 재작업:
   - 태블릿 구간: `background-size`를 고정값이 아닌 **폭 비율(%)**
     (`254% auto`)로 지정해 컨테이너 폭이 바뀔 때 코인 크기/간격이
     비례해서 스케일되도록 함(코드 주석에 "위치 점프 방지" 목적이라고
     기록됨). 폭이 가장 좁은 769px 근처에서 이미지 높이가 프레임(580px)을
     못 채우는 트레이드오프가 있어 `background-color: #3a0f0a`로 여백을
     가림.
   - 모바일 구간: 텍스트 상단/코인 하단 분리 레이아웃을 다시 도입하되,
     `fd8beb1`의 단색(#1a0f0a) 채움 대신 이미지에서 추출한 빨강→황토
     그라디언트를 3중 `background-image` 레이어(어둡게 하는 그라디언트 +
     원본 이미지 + 배경 그라디언트)로 구성.
   - **제목 텍스트는 영문화하지 않음** — `fd8beb1`의 제목 변경분은 이미
     `f658a6b`에서 되돌아갔고, `1e856b9`는 `index.html`을 건드리지
     않았으므로 현재 제목은 한글(`'2027 양띠<br>골드 코인'`) 상태 유지.

   현재 `HEAD`(`3b6442c`, 자동 생성 커밋)까지 이후 goat-2027 관련 코드
   변경은 없음 — **`1e856b9`가 현재 배포된 최종 상태**입니다.

7. `git status` 확인 결과 작업 트리는 깨끗하며(clean), 로컬 저장소는
   `origin/main`과 일치합니다.
8. 이번 세션(f0586f2~1e856b9) 중 **새 백업 브랜치는 생성되지 않음** —
   `git ls-remote`로 확인한 결과 가장 최근 백업 브랜치는 여전히
   `backup-2026-09-11-1831`(기준 커밋 `c188824`, 직전 세션에서 생성)이며,
   `ed652d6`/`fa88bb1`의 이미지 재합성처럼 비가역적 시각 변경이 있었음에도
   이번 6개 커밋 구간에는 새 백업이 없음. 직전 세션 인수인계에 "이미지
   재합성은 비가역적 변경이므로 백업 생성" 원칙이 기록돼 있었으나 이번
   세션에서는 지켜지지 않은 것으로 보임 [영향 낮음] — CSS 4곳 + 이미지
   1개 변경 정도라 롤백 필요 시 `backup-2026-09-11-1831`에서 크게 벗어나지
   않은 범위로 수동 비교 가능하기 때문.

### 미확인 (diff만으로는 알 수 없음)

- **`f658a6b`가 `fd8beb1`을 되돌린 이유** — 사용자 피드백(예: "영문 제목이
  안 맞는다", "레이아웃이 이상하다") 때문인지, 아니면 작업 중 실수를
  스스로 발견해 되돌린 것인지 커밋 메시지에 근거가 없어 알 수 없음.
- **실제 브라우저/실기기 렌더링 확인 여부** — 직전 세션(`2026-09-11-1832`)은
  PIL 시뮬레이터로 모바일 배치를 미리 검증했다는 기록이 있었지만, 이번
  6개 커밋에는 그런 검증 방법이 커밋 메시지에 전혀 언급되어 있지 않음.
  특히 `1e856b9`의 3중 레이어 `background-image`(그라디언트+이미지+
  그라디언트) 조합이 실제 브라우저에서 의도대로 렌더링되는지, 태블릿
  구간의 `254% auto` 폭 비율 스케일링이 실제로 "위치 점프"를 막는지는
  **미확인**.
- **`fd8beb1`에서 시도했던 영문 제목(`Year of the Goat`)이 왜 폐기됐는지** —
  레이아웃과 함께 통째로 revert된 것이라 제목 자체에 대한 별도 판단이
  있었는지는 알 수 없음. 다음 세션에서 사용자에게 이 부분이 의도적
  폐기인지 확인 필요.
- **`ed652d6`/`fa88bb1`의 이미지 재합성 스크립트** — 레포에 커밋되지
  않았고(직전 세션과 동일 패턴으로 추정), 이번 대화 로그도 없어 재합성
  로직 자체는 복원 불가.
- 다른 4개 슬라이드(이글/버팔로/필하모닉/캥거루)의 모바일 크롭 문제는
  이번 6개 커밋에서도 다루지 않음(직전 핸드오프에서도 미해결로 이월된
  항목).

## 3. 진행 단계 (재사용 가능 메모, diff 코드 주석 기반)

- **모바일 `background-size` 선택 시 주의**: goat-2027 원본 이미지 비율상
  `150% auto`처럼 `cover`보다 작은 배율을 쓰면 슬라이더 높이(400px)를
  못 채워 컨테이너 배경(#111)이 위아래로 노출됨. `cover` 이상을 유지하거나,
  최종 채택된 것처럼 `background-color`로 여백을 가리는 방식을 써야 함.
- **태블릿 구간 "위치 점프" 방지 패턴**: `background-size`를 고정 배율이
  아닌 **폭 비율(%)**로 주면(`1e856b9`에서 `254% auto` 사용) 컨테이너
  폭이 바뀔 때 코인 크기/간격이 함께 스케일되어 배치가 급격히 바뀌는
  현상을 줄일 수 있음(코드 주석 기준, 실제 브라우저 확인은 미확인). 다른
  슬라이드에 동일 패턴 적용 시 이미지별 좌표에 맞춰 배율 값 재계산 필요.
- **모바일 텍스트/코인 겹침 회피 패턴**: `align-items: flex-start`로
  텍스트를 상단 고정하고, 코인 이미지는 `background-position: ... bottom`
  으로 하단 배치, 남는 공간은 이미지에서 추출한 그라디언트 레이어로
  채우는 3중 `background-image` 구성. `fd8beb1`(단색 채움)에서
  `1e856b9`(그라디언트 채움)로 개선된 버전.
