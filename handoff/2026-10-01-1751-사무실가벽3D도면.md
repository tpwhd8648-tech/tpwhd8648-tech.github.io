## 1. 목표

**완료된 산출물 (모두 채팅 안 위젯으로만 표시됨, 파일로 저장된 것은 없음)**

- 3D 등각도: A안만 (아래 5번 스크립트로 생성)

**2D 평면 기준 A~D 정의 (좌표: u = 가로 0~4m 왼쪽→오른쪽, v = 출입구에서 발코니 쪽 깊이 0~7.5m)**

| 안 | 이름 | 응대실 영역 | 커튼 위치 | 열리는 곳 | 커튼 길이(개구부 제외) |
|---|---|---|---|---|---|
| A | 일자 분할 | v 0~3.5, u 0~4 | v=3.5, u 1~4 | u 0~1 | 3m |
| B | 모서리 ㄱ자 | u 1.5~4, v 0~3 (2.5×3m) | u=1.5(v 1~3) + v=3(u 1.5~4) | u=1.5 선상 v 0~1 | 4.5m |
| C | 발코니 쪽 | v 4.5~7.5, u 0~4 | v=4.5, u 1~4 | u 0~1 | 3m |
| D | 대기 + 응대 | v 1.5~4.5, u 0~4 (3m) | v=1.5(u 0~1, 2~4) + v=4.5(u 0~4) | v=1.5 선상 u 1~2 | 7m |

| 안 | 이름 | 응대실 영역 | 커튼 위치 | 열리는 곳 | 커튼 길이(개구부 제외) |
|---|---|---|---|---|---|
| E | 2칸 응대실 (동시 상담) | 왼쪽 u 0~2, 오른쪽 u 2~4, 둘 다 v 1.5~5 | v=1.5(u 0~0.5, 1.3~2.7, 3.5~4) + u=2(v 1.5~5) + v=5(u 0~4) | 각 방 앞쪽 u 0.5~1.3, u 2.7~3.5 | 약 9.9m |
| F | 중앙 부스 | u 0.75~3.25, v 2.5~5.5 (2.5×3m) | 사방 직사각형 둘레, 양옆 통로 0.75m | 앞면(v=2.5) 중앙 1m | 약 10m |

## 5. 참고 사항

**결정의 이유**
- 커튼이 선택된 이유: 방음이 필요 없고 셀프 시공이며 비용이 가장 낮기 때문이다. 석고보드·유리 가벽은 비교만 했고 채택하지 않았다.
- A안을 추천한 이유: 업무공간이 거의 없어 응대실을 넓게 잡고 직선 레일 한 줄로 끝내는 편이 가장 싸다.

**불일치 주의**
- 대화 초반에 "ㄱ자 5.5m"라고 한 것은 개구부 없이 둘러싼 길이다. 도면 기준(개구부 1m 제외)은 4.5m다. 표의 값이 도면 기준이다.
- D안은 대화에서 "일자 8m"라고 했지만 도면 기준(개구부 1m 제외)은 7m다.
- 사용자가 아직 확인하지 않은 값(층고 2.4m 등)을 사실처럼 말하지 않는다.

**3D 도면 제작 시 주의 (이번 세션에서 확인한 것)**
- 위젯 규칙: SVG는 `viewBox="0 0 380 H"`, 모든 `<text>`에 `class="t|ts|th"` 필수, 폰트 11px 미만 금지, 이모지 금지, 한 호출에 SVG 하나.
- 3D 장면의 색은 하드코딩 hex를 쓴다(다크모드에서 뒤집히지 않게). 그 대신 글자는 흰 배경 위에 두면 다크모드에서 안 보이므로, 도면 위 라벨은 **번호 배지(흰 원 + 검은 글자)** 로 쓰고 설명은 도면 아래 투명 영역의 범례에 둔다.
- 투영식: `sx = 256 + (u - v)*a`, `sy = 290 - (u + v)*b - z*s`, `s=30, a=0.866*s, b=0.5*s`. 가장 가까운 모서리가 (u=0, v=0)이라 출입구 쪽 벽은 낮은 벽(0.25m)으로, 발코니 쪽 벽과 오른쪽 벽(u=4)은 천장 높이로 그린다.
- 그리는 순서(먼 것 → 가까운 것)가 중요하다: 발코니 → 바닥 → 응대실 바닥색 → 오른쪽 벽 → 뒤쪽 벽 → 커튼 → 낮은 벽 → 가구 → 배지. **커튼은 v값이 큰 것부터** 그리고, 커튼보다 가까운(v 작은) 가구는 커튼 뒤에 그린다. 커튼 뒤쪽(v가 큰 쪽) 공간은 커튼에 가려 보이지 않는 것이 정상이다.
- 커튼 주름: 12조각으로 나누고 조각마다 v에 ±0.07m 오프셋을 번갈아 주고 색을 번갈아(#F0997B / #D85A30) 칠하면 입체감이 난다.
- 가로 방향 커튼(v 고정)은 `P(u, v, z)`의 u만 바꿔 그리면 된다. u 고정인 세로 커튼(B·E·F·G)은 v만 바꾸고 오프셋을 u에 준다. 세로 커튼의 폴리곤 앞뒤 순서는 오른쪽 벽 쪽에서 왼쪽으로 가는 방향이 먼 쪽이다.
- 방(응대실) 영역 바닥색은 `#9FE1CB`로 직사각형을 `poly([(u0,v0),(u1,v0),(u1,v1),(u0,v1)], ...)`로 칠한다. 안마다 이 좌표만 바꾼다.
- 범례(하단)는 `pos` 목록과 `leg` 목록만 바꾼다. 항목이 5개를 넘으면 viewBox 높이(400)를 늘린다. 마지막 요소 y + 약 20.
- 이 환경에서 확인한 것은 A안 렌더링뿐이다. 세로 커튼(B·E·F·G)의 폴리곤 순서는 아직 실제로 그려본 적이 없으니 렌더 결과를 보고 겹침을 확인한다.

**안별 수정 방법 (gen.py)**
- 커튼: `n=12; us=...` 블록을 안별 선분 목록으로 바꾼다. 선분마다 (시작, 끝, 고정축)을 정해 반복한다.
- 응대실 바닥색: `poly([(0,0),(W,0),(W,R),(0,R)],"#9FE1CB")` 줄의 좌표를 안별 영역으로 바꾼다. 변수 `R`은 A안의 커튼 위치(3.5)다.
- 가구: `tu0,tu1,tv0,tv1`과 `for (cu,cv) in [...]`를 방 중심에 맞게 옮긴다. E안은 방마다 1세트, F안은 부스 중앙에 1세트를 둔다.
- 배지: `badge((u,v,z),번호)` 위치를 안별로 옮긴다.

**gen.py (A안, 그대로 실행 가능 — 이 코드가 A안 3D 도면을 만든 원본)**

s=30.0; a=0.866*s; b=0.5*s; ox=256; oy=290
def P(u,v,z=0): return (ox+(u-v)*a, oy-(u+v)*b-z*s)
def pt(*args): x,y=P(*args); return f"{x:.1f},{y:.1f}"
def poly(pts,fill,stroke="#5F5E5A",sw=0.6,extra=""):
    return f'<polygon points="{" ".join(pt(*p) for p in pts)}" fill="{fill}" stroke="{stroke}" stroke-width="{sw}" stroke-linejoin="round" {extra}/>'
def line(p1,p2,stroke="#5F5E5A",sw=1,extra=""):
    x1,y1=P(*p1);x2,y2=P(*p2)
    return f'<line x1="{x1:.1f}" y1="{y1:.1f}" x2="{x2:.1f}" y2="{y2:.1f}" stroke="{stroke}" stroke-width="{sw}" {extra}/>'
W=4.0; D=7.5; H=2.4; R=3.5
o=[]
# balcony floor
o.append(poly([(0,D,0),(W,D,0),(W,8.3,0),(0,8.3,0)],"#B5D4F4"))
# balcony railing
o.append(line((0,8.3,1),(W,8.3,1),"#5F5E5A",1.2))
o.append(line((0,D,1),(0,8.3,1),"#5F5E5A",1.2))
o.append(line((W,D,1),(W,8.3,1),"#5F5E5A",1.2))
for u in (0,1,2,3,4):
    o.append(line((u,8.3,0),(u,8.3,1),"#5F5E5A",1))
for v in (D,8.3):
    o.append(line((0,v,0),(0,v,1),"#5F5E5A",1))
    o.append(line((W,v,0),(W,v,1),"#5F5E5A",1))
# floor
o.append(poly([(0,0),(W,0),(W,D),(0,D)],"#F1EFE8"))
o.append(poly([(0,0),(W,0),(W,R),(0,R)],"#9FE1CB"))
# right wall u=W
o.append(poly([(W,0,0),(W,D,0),(W,D,H),(W,0,H)],"#B4B2A9"))
# back wall pieces
o.append(poly([(0,D,0),(1,D,0),(1,D,H),(0,D,H)],"#D3D1C7"))
o.append(poly([(3,D,0),(W,D,0),(W,D,H),(3,D,H)],"#D3D1C7"))
o.append(poly([(1,D,2.1),(3,D,2.1),(3,D,H),(1,D,H)],"#D3D1C7"))
# curtain pleats u=1..4 at v=R
n=12; us=[1+3*i/n for i in range(n+1)]
for i in range(n):
    off0=0.07 if i%2==0 else -0.07
    off1=-off0
    col="#F0997B" if i%2==0 else "#D85A30"
    o.append(poly([(us[i],R+off0,0.05),(us[i+1],R+off1,0.05),(us[i+1],R+off1,H),(us[i],R+off0,H)],col,"#993C1D",0.4))
o.append(line((1,R,H),(W,R,H),"#444441",2.5))
# low walls (left u=0, entrance v=0)
h=0.25
o.append(poly([(0,0,0),(0,D,0),(0,D,h),(0,0,h)],"#888780"))
o.append(poly([(0,0,0),(0.4,0,0),(0.4,0,h),(0,0,h)],"#888780"))
o.append(poly([(1.3,0,0),(W,0,0),(W,0,h),(1.3,0,h)],"#888780"))
# table and chairs
def box(u0,v0,u1,v1,z1,top,left,right):
    r=[]
    r.append(poly([(u1,v0,0),(u1,v1,0),(u1,v1,z1),(u1,v0,z1)],right))
    r.append(poly([(u0,v0,0),(u1,v0,0),(u1,v0,z1),(u0,v0,z1)],left))
    r.append(poly([(u0,v0,z1),(u1,v0,z1),(u1,v1,z1),(u0,v1,z1)],top))
    return r
tu0,tu1=1.5,2.7; tv0,tv1=1.3,2.1
o+=box(tu0,tv0,tu1,tv1,0.75,"#EF9F27","#BA7517","#854F0B")
cs=0.4
for (cu,cv) in [(1.75,0.65),(2.35,0.65),(1.75,2.55),(2.35,2.55)]:
    o+=box(cu,cv,cu+cs,cv+cs,0.45,"#7F77DD","#534AB7","#3C3489")
def badge(p,n):
    x,y=P(*p)
    return f'<circle cx="{x:.1f}" cy="{y:.1f}" r="9" fill="#FFFFFF" stroke="#2C2C2A" stroke-width="1"/><text class="ts" x="{x:.1f}" y="{y:.1f}" text-anchor="middle" dominant-baseline="central" style="fill:#2C2C2A">{n}</text>'
o.append(badge((0.85,-0.55,0),1))
o.append(badge((3.3,0.9,0),2))
o.append(badge((3.0,R,1.3),3))
o.append(badge((0.5,R,0.0),4))
o.append(badge((2.0,8.1,0),5))
svg='\n'.join(o)
# legend
leg=[(1,"출입구 (0.9m)"),(2,"응대실 4×3.5m"),(3,"천장 커튼 레일 3m"),(4,"열리는 통로 1m"),(5,"발코니")]
L=[]
pos=[(30,335),(30,358),(30,381),(205,335),(205,358)]
for (n,t),(x,y) in zip(leg,pos):
    L.append(f'<circle cx="{x+9}" cy="{y}" r="9" fill="#FFFFFF" stroke="#2C2C2A" stroke-width="1"/><text class="ts" x="{x+9}" y="{y}" text-anchor="middle" dominant-baseline="central" style="fill:#2C2C2A">{n}</text><text class="ts" x="{x+24}" y="{y}" dominant-baseline="central">{t}</text>')
full='<svg width="100%" viewBox="0 0 380 400" role="img"><title>사무실 3D 도면 A안</title><desc>가로 4m 세로 7.5m 사무실의 등각 3D 도면. 출입구 쪽 3.5m를 천장 커튼으로 구획한 응대실과 뒤쪽 발코니.</desc>\n'+svg+'\n'+'\n'.join(L)+'\n</svg>'
open('/tmp/out.svg','w').write(full)
print(len(full))
xs=[]
import re
for m in re.finditer(r'points="([^"]+)"',full):
    for p in m.group(1).split():
        x,y=map(float,p.split(',')); xs.append((x,y))
print(min(x for x,y in xs),max(x for x,y in xs),min(y for x,y in xs),max(y for x,y in xs))
