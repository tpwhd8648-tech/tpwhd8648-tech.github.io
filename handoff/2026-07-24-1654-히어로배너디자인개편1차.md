직전 핸드오프(`2026-07-24-1623-코인타이틀SEO및브랜드소개페이지신설.md`)에서 계속

사용자가 지목한 문제(성 조지 히어로 슬라이드 밋밋함, 카테고리 배너 3개 이미지

### (2) 카테고리 배너 3개 실제 상품 사진으로 교체 (반영 완료 — 커밋 `787876a`, push 완료)

- 대상 파일: `assets/css/style.css` (`.cat-gold`/`.cat-silver`/`.cat-collectible`, 91~93줄)
- 변경 전: 3개 배너 모두 외부 **Unsplash 스톡 사진**(장신구 일반 이미지, 브랜드
  상품과 무관) + 색깔 그라데이션 + `background-blend-mode: multiply`
- 변경 후: 실제 상품 사진(히어로 슬라이드에 쓰던 이미지 재사용) + 히어로
  슬라이드와 동일한 어두운 그라데이션 오버레이(`rgba(0,0,0,0.15)→0.55`)만 얹는
  방식. `background-blend-mode: multiply` 제거 — 색 그라데이션이 사진을 탁하게
  가리는 문제를 없앰.
- 매핑: 금화 배너 → 아메리칸 이글 사진, 금 시세 배너 → 아메리칸 버팔로 사진,
  문의 배너 → 오스트레일리아 캥거루 사진 (사용자 확정, 특별한 의미 매핑은 아님)
- 이미지 경로: `assets/css/style.css` 기준 `../../images/header-slide-*.jpg`
  상대경로 사용 — CSS 파일 위치(`assets/css/`)에서 저장소 루트의 `images/`
  폴더까지 두 단계 상위 이동 (index.html의 기존 참조 방식과 일치 확인).
- 검증: CSS 중괄호 균형 확인(Python 인라인) — 이상 없음.
- **사용자가 배포 후 실제 화면 보고 "안 괜찮으면 다시 바꾸겠다"고 한 상태** —
  최종 확정 아니고 결과 확인 대기 중.

### (3) 히어로 영상 슬라이드 추가 (진행 중 — 영상 소스 미제작, 코드 미반영)

- 목표: 다른 4개 슬라이드(특정 코인 소개)와 달리, **브랜드 철학(검증 프로세스)을
  다루는 영상 배경 슬라이드 1개**를 5번째로 추가해 5개 슬라이드 유지.
- **무료 스톡 영상 탐색 결과 — 적합한 것을 찾지 못함**:
  - Pexels에서 "여러 국가 공인 금화(아메리칸 이글/메이플리프/브리태니아 등)"가
    실제로 나오는 무료 영상을 검색했으나, 결과는 대부분 비트코인/크립토 소품
    영상이거나 3D 게임용 코인 애니메이션이었음. 정확히 맞는 소재(여러 국가
    금화 나열)는 Getty/iStock/Adobe Stock 등 **유료** 소스에만 있음을 확인.
  - 후보로 검토했던 두 영상(금괴 CG 애니메이션 8733007, 스택 코인 실사
    8369972)은 각각 "디지털 애니메이션이라 실물 검증 브랜드 철학과 안 맞음",
    "Pexels 태그상 비트코인 소품이라 실물 순금화와 무관"이라는 이유로
    보류됨.
  - 기존 사이트 이미지(이글/버팔로/캥거루/필하모닉 사진)를 이어붙여 영상처럼
    만드는 방안도 논의했으나, 원본 사진의 저작권 출처(직접 촬영 vs 조폐국
    보도자료 vs 스톡 구매)가 불명확해 사용자가 보류함.
- **최종 결정**: 사용자가 외부 AI 영상 생성 툴(런웨이/클링 등)로 직접 새 영상을
  제작하기로 함. 프롬프트(영문+국문)를 작성해 전달함 — 특정 조폐국 로고나
  정확한 코인 각인은 상표 문제 소지가 있어 프롬프트에서 제외하고 "여러 국가
  금화 느낌"만 담도록 작성.
- **다음 세션에서 할 일**: 사용자가 영상 파일을 업로드하면, 저장소에 파일을
  넣고 `heroSlides` 배열에 5번째 슬라이드(비디오 배경)로 추가. 배지/타이틀
  문구 초안("OneTroy Bullion · Our Promise" 등)은 이미 논의해뒀고, 버튼은
  `pages/about.html`로 연결 예정. 기술적으로 `muted playsinline loop
  autoplay` + `poster` 폴백 이미지 + `prefers-reduced-motion` 대응 필요.
