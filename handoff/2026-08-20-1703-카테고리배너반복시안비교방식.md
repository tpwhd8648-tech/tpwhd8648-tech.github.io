# 카테고리 배너 반복 시안 비교 방식 인수인계 문서

작성일: 2026-08-20 17:03 (KST)

## 1. 목표

`index.html` 카테고리 배너(`.cat-gold`/`.cat-silver`/`.cat-collectible`) 디자인을
"무난함" 기준으로 확정하기 위한 작업. 5차례 세션째 이어지는 작업이며, 이번
세션에서 **작업 방식 자체를 사용자와 합의**함 — 앞으로는 매 라운드 3개 시안을
만들어 보여주고, 마음에 드는 게 없으면 사용자 피드백을 반영해 다음 라운드
3개를 새로 만드는 방식(브랜드명 정할 때와 동일한 방식)으로 계속 좁혀간다.
**아직 최종 결정 안 남 — 다음 세션은 3라운드부터 이어서 진행.**

## 2. 현재 상태

### (1) 작업 방식 합의 (확인 완료)

- 사용자가 명시: "하나 골라서 승인/반려" 방식이 아니라, **매번 3개 시안을
  만들어서 비교 → 마음에 안 들면 새로운 3개를 또 만들어서 비교**하는 방식을
  계속 반복하고 싶어함
- 이 방식은 카테고리 배너뿐 아니라 향후 다른 디자인 결정(마스코트, 히어로 등)에도
  적용 가능한 원칙으로 채택하기로 함 (사용자가 명시적으로 확대 요청한 것은
  아니나, 같은 패턴의 반복 요청이 있을 경우 참고)
- **판단 기준**: "무난함"이 최우선. 패턴/컬러가 튀거나 시선을 분산시키는
  요소는 배제 방향

### (2) 1라운드 — A안/1안/2안 (확인 완료, 사용자가 셋 다 반려)

- A안(현재 사이트 반영 상태): 연화 톤 low-poly + 방사형 스크림
  → 사용자 피드백: "너무 눈에 띈다"
- 1안: low-poly 패턴 유지하되 대비·채도·음영 압축 (더 차분한 버전)
- 2안: low-poly 패턴 완전 제거, 골드/실버/브론즈 단순 선형 그라디언트
- **사용자 반응**: "3개(2안) 중에는 나은데 딱히 끌리진 않는다" → 3개 모두 반려,
  다음 라운드로

### (3) 2라운드 — 3안/4안/5안 (확인 완료, 사용자가 아직 반응 안 함 — **다음 세션
  시작 시 먼저 이 3개에 대한 피드백부터 받을 것**)

지오메트릭 패턴(low-poly, 그라디언트) 계열에서 벗어나 완전히 다른 컨셉 3개 제시:

- **3안 브러시드 메탈**: 가느다란 수평 결 무늬로 금속 표면 질감 표현
- **4안 길로셰**: 지폐/증서에 쓰이는 얇은 곡선 격자 패턴 (화폐·귀금속 테마와
  개념적으로 잘 맞음, 단 스크린샷 확인 결과 패턴이 거의 안 보일 정도로 옅어서
  다음 라운드에서는 강도를 올려볼 필요 있음)
- **5안 보케 블러**: 초점 나간 부드러운 원형 빛망울

## 3. 진행 단계

1. (지난 세션들) low-poly 방식 확정 및 A안 반영까지 완료 — 여기까지는 이전
   handoff 참고 (`2026-08-07-1621-카테고리배너low-poly.md`)
2. 이번 세션: 사용자가 "A안이 너무 눈에 띈다"고 지적 → 1안(다듬은 low-poly)/
   2안(단순 그라디언트) 추가 생성, Python(numpy+scipy)으로 SVG 생성 →
   Playwright로 비교 스크린샷 제작해 공유
3. 사용자가 작업 방식에 대해 먼저 논의를 요청 → "3개씩 반복 비교" 방식으로
   합의
4. 2라운드(브러시드 메탈/길로셰/보케 블러) 시안 생성 → 비교 스크린샷 공유 →
   사용자가 코드 작업 대신 인수인계 문서 작성 요청 (이 문서)

## 5. 참고 사항

  SVG 파일과 비교용 HTML은 아직 레포에 커밋되지 않음 — 작업 컨테이너
  임시공간(`/home/claude/lowpoly/`)에만 존재하며 **이 세션 종료 시 유실됨**.
  다음 세션에서 스크린샷(이 문서와 함께 전달된 PNG 2장: `카테고리배너_비교.png`,
  `카테고리배너_2라운드.png`)을 참고해 필요하면 동일한 로직으로 재생성
  가능. 재생성 스크립트 로직은 아래 "재생성 참고" 항목 참고.
  - **주의**: 지난 세션(2026-08-07)에서 프리뷰 파일이 임시공간에만 있다가
    유실된 전례가 있었음(그래서 A안/B안 SVG 6종은 이미 레포
    `assets/images/banners/`에 저장돼 있음). 이번 1/2라운드 신규 SVG는
    아직 최종 결정 전이라 레포에 커밋하지 않은 상태 — 다음 세션에서 최종안이
    정해지면 그때 레포에 저장할 것.
- **재생성 참고**:
  - 1라운드(1안 무디드 low-poly, 2안 그라디언트) 생성 로직: Delaunay
    삼각분할 기반 기존 스크립트(`scripts/generate-category-banners.py`)를
    변형 — 채도/명암 스톱 값을 완화하고 `height_scale`, `z_amp`를 낮춰
    음영차를 줄임. 2안은 단순 `linearGradient` SVG.
  - 2라운드(3안 브러시드메탈, 4안 길로셰, 5안 보케블러) 생성 로직:
    - 브러시드 메탈: 그라디언트 배경 위에 반투명 흰/검 수평선 100여 개를
      무작위 opacity로 겹쳐 결 표현
    - 길로셰: 그라디언트 배경 위에 sin 곡선 기반 얇은 곡선 20여 개를
      낮은 opacity(0.12)로 겹침 — **다음 라운드에선 opacity를 올려서
      패턴이 더 보이게 조정 필요**

      `feGaussianBlur` 필터로 블러 처리
  - 골드/실버/브론즈 공통 베이스 그라디언트 색상: 골드 `#8A6E3E→#C9A85E→#E8CD94`,

- **비교 방식**: 매 라운드마다 3개 컨셉 × 3색(gold/silver/bronze) = 9개 SVG를
  생성한 뒤, `.cat-overlay`(방사형 스크림)와 `.cat-content`(텍스트/버튼)를
  포함한 실제 배너 레이아웃으로 HTML 프리뷰를 만들고, Playwright로 스크린샷
  찍어 사용자에게 이미지로 공유하는 방식이 효율적이었음. 다음 세션도 이
  워크플로우(SVG 생성 → HTML 프리뷰 조립 → Playwright 스크린샷 → present_files)
  그대로 사용할 것.
