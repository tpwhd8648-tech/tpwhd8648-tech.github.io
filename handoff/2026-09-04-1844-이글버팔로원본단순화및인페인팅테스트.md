## 3. 진행 단계 (재사용 가능 절차)

### 3-1. "원본 배경 + 상품 원본 그대로 얹기" 절차 (이번에 채택한 최종 방식)

1. **pristine 배경 확보(필수)**: `git show <압축 전 커밋>:<path>` 로 최초 원본 복원
   (이번엔 `7e7f33a`).
2. **옛 코인 좌표 파악(필수)**: `cv2.HoughCircles`로 옛 코인의 중심좌표·반지름을
   찾는다 (그레이스케일 변환 + `medianBlur` 후 적용). 후보가 여러 개 나오면 시각화해서
   실제 코인과 가장 일치하는 것을 눈으로 확인한다 (버팔로처럼 주변에 비슷한 크기의 물체가
   있으면 여러 후보가 나올 수 있음).
3. **상품 원본 컷아웃(필수, 가공 없음)**: 상품 스튜디오 사진(흰 배경)에서 `gray < 248`
   임계값으로 알파 마스크 생성 → `MORPH_CLOSE`/`MORPH_OPEN`으로 잡티만 정리. 색보정,
   블러, 페더링은 **적용하지 않음** (사용자가 명시적으로 "그냥 띡" 방식을 요청함).
4. **크기 결정 및 합성(필수)**: 옛 코인 반지름 대비 최소 100% 이상(안전하게는 +8%
   정도)으로 새 코인을 리사이즈해 옛 코인 중심에 그대로 paste. **이 배율보다 작게 하면
   옛 코인이 비쳐 보이므로 절대 축소하지 않는다** (3-2 참고).
5. **결과물 크기가 원본과 동일한지 확인(필수)**.
6. **`present_files`로 전달 후 승인 받고 반영(필수)**.

### 3-2. 코인을 지금보다 작게 만들고 싶을 때 (현재는 미해결 — 참고용 기록)

1. 옛 코인 영역을 먼저 지워야 함 (`cv2.inpaint` Telea 방식은 **실패 확인됨**, 사용 금지).

   시작할 것.
3. 배경이 자연스럽게 채워진 것을 확인한 뒤에만 3-1의 4번 단계를 원하는 크기(축소 포함)로

## 5. 참고 사항

- **"그냥 붙이기"의 성립 조건**: 새 코인이 옛 코인과 같거나 클 때만 성립한다. 작게
  하려면 반드시 옛 코인 자리를 먼저 지워야 하며, 이번 세션에서 이 개념 검증을 위해
  실제 이미지로 시연함 (인페인팅 없이 작게 → 옛 코인 비침 / 인페인팅 후 작게 → 방사형
  얼룩 강조).
- **인페인팅 테스트 이미지는 레포에 남기지 않기로 결정**: GitHub Pages가 레포 루트를
  그대로 서빙해 실패한 이미지도 공개되는 점, 재사용 가치가 낮은 점(다음에 생성형
  인페인팅으로 다시 하면 결과가 달라짐)을 고려해 이미지 파일 대신 이 문서(3-2, 옛 코인
  좌표 포함)로만 기록하기로 함. 나중에 필요하면 이 문서의 좌표(이글: 중심 949,246
  반지름 154 / 버팔로: 중심 1210,320 반지름 195)로 바로 재현 가능.
- **Hough Circle 팁**: `param2` 값(50 근처)과 `minDist`를 배경 특성에 맞게 조정해야
  하고, 버팔로처럼 주변에 비슷한 크기·색의 물체(뿔, 바위)가 있으면 여러 후보가 나오므로
  반드시 시각화해서 실제 코인과 일치하는지 눈으로 확인해야 한다 (자동으로 첫 번째 결과를
  신뢰하지 말 것).
- **백업 브랜치**: 이번 세션도 이미지 파일 2개 교체(git 히스토리로 되돌리기 쉬움)라
  별도 백업 브랜치는 생성하지 않음. 최신 백업은 여전히 `backup-2026-08-20-1755`.
  문제 발견 시 `git revert dc74e7b` 또는 `b01df9b` 시점으로 해당 파일만 되돌리는 방식
  고려 가능.
