# 2027 양띠 코인 히어로 슬라이드 추가 인수인계 문서

작성일: 2026-09-11

> **나중에 이 작업을 다시 찾을 때 검색 키워드**: "2027 양띠 히어로 슬라이드",
> "header-slide-goat-2027", "코인 앞뒤 합성 히어로", "정미년 배경 생성"

## 1. 목표

기존 히어로 슬라이더(이글/버팔로/캥거루/필하모닉)에 2027 양띠(루나 시리즈 3) 골드
코인 슬라이드를 새로 추가하는 것. 사용자가 참고 이미지(플랫 일러스트 스타일 배너)를
보여줬으나, 검토 후 기존 4장과 톤을 맞추기 위해 **실사 합성 스타일(A안)**로 진행하기로
결정함. 코인 이미지는 처음엔 제외하고 배경만 먼저 만든 뒤, 이어서 앞면/뒷면 코인 이미지를
모두 합성함.

  - `slug: 'goat-2027'` → `coins/coin-goat-2027.html`로 정상 연결 (해당 페이지는

- 미리보기 이미지를 Python으로 별도 렌더링해 사용자에게 확인받음. 이 과정에서
  **미리보기 스크립트가 코인 합성 전 배경 파일을 읽는 경로 버그**가 있었음
  (코인 합성 결과는 레포 경로에만 저장되고, 미리보기는 작업 스크래치 경로의
  구버전 파일을 참조) → 경로 수정 후 재확인. 이후 사용자가 모바일에서 이미지가
  안 보인다고 재차 보고 → 파일을 확인해보니 내용 자체는 정상이었고, 동일
  파일명을 반복 덮어써서 생긴 클라이언트 캐시 문제로 추정, 파일명을 바꿔서
  재전송한 뒤 정상 확인됨

  별도 파일로 검증 — `index.html` 자체는 `.html`이라 `node --check` 직접 적용 불가)
- Git 작업: `git fetch origin main`으로 원격 최신 확인(원격 최신 커밋과 작업 시작
  시점 커밋이 동일 — 리베이스 불필요) → `git add` → `git commit`(커밋 중 git
  author identity 미설정 오류 발생, `git config user.email/name` 설정 후 재시도해
  해결) → `git fetch` 재확인(그 사이 새 원격 커밋 없음 확인) → `git push` → 사용자
  요청대로 PAT는 push 직후 remote URL을 plain HTTPS로 즉시 원복
- **커밋 `37246f7`** push 완료, `git ls-remote origin refs/heads/main`으로
  원격 반영 확인함(로컬 HEAD와 해시 일치)

## 3. 진행 단계 (재사용 가능 절차 — 히어로 슬라이드 배경에 코인 합성 시)

1. 배경 이미지 절차적 생성 (필요 시 테마 색상만 교체): 라디얼 그라디언트 +
   저채도 패턴 아크 + 그레인 노이즈. 사이트 CSS가 좌측 어둡게 처리를 담당하므로
   배경 자체에는 넣지 않는다(중복 방지).
2. 코인 원본이 흰 배경 정사각형 PNG인 경우: non-white 영역 bbox로 중심/반지름
   추정 → 원형 마스크(feather) 생성 → RGBA 변환 → 크롭.
3. 드롭섀도우: 알파 채널 기반 그림자 레이어 생성 후 GaussianBlur, 원본 코인과
   합성.
4. 크기 배치 시 반드시 **패딩 포함 최종 캔버스 크기**를 기준으로 좌표를 계산할
   것 (그림자 blur padding을 안 챙기면 코인이 배너 밖으로 잘려나가는 실수가
   재발할 수 있음 — 이번 세션에서 실제로 겪음).
5. `heroSlides` 배열에 항목 추가 후 `node --check`(스크립트 블록만 추출해서
   검증, `.html` 파일 자체는 불가).
6. 미리보기 렌더링 스크립트는 **반드시 합성 완료된 레포 경로의 최종 이미지**를
   읽도록 경로를 재확인할 것 (이번 세션에서 스크래치 경로의 구버전을 읽는
   버그가 실제로 발생함).
7. 사용자에게 미리보기 공유 시, 같은 파일명을 반복 덮어써서 전송하면 모바일
   클라이언트가 캐시된 이전 버전을 보여줄 수 있으므로, 재전송이 필요한 경우
   파일명을 바꿔서 전달한다.

  저장하지 않음.
