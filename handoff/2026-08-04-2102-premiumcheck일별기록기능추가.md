# premium-check.html 일별 기록 기능 인수인계 문서

작성일: 2026-08-04

## 1. 목표
`premium-check.html`(메이플리프 vs 최저premium 가격차를 실시간으로 확인하는 내부 진단용 페이지)에, 그날그날의 결과를 자동으로 쌓아 추세를 볼 수 있는 "일별 기록" 기능을 추가했다. 또한 과거(최근 90일) 데이터도 실제 시세를 이용해 근사적으로 채워 넣었다.

**완료된 것 (확인 완료 — node --check로 JS 문법 검증, 실제 배포 후 코드 리뷰):**
- 접속/새로고침 시 오늘 날짜로 결과(메이플리프가, 최저가 상품, 가격차이)를 브라우저 `localStorage`에 자동 저장 (같은 날 재확인 시 최신값으로 덮어씀)
- 카드 하단에 "일별 기록" 테이블 추가, 전일 대비 증감(▲/▼) 표시
- "기록 초기화" 버튼으로 localStorage 리셋 가능
- **과거 90일치 백필**: 최초 1회, 아래 실제 무료 API 두 개를 조합해 자동 채움
  - 금시세(XAU/USD): `https://xaus.com/api/v1/history` — 키 불필요, CORS 오픈, 최대 5년 일봉 데이터 제공
  - 환율(USD/KRW): `https://api.frankfurter.dev/v1/{시작일}..{종료일}?from=USD&to=KRW` — ECB 공식 데이터, 키 불필요
  - 계산식은 기존 실시간 로직과 동일 (`금시세 × 환율 × premium`, 1000원 단위 반올림)
  - 백필된 행은 회색 글�씨 + "추정" 뱃지로 실측 기록과 구분
- 백필 실행 여부는 `localStorage`의 `premiumCheckBackfilledV3` 플래그로 관리 (버전을 올리면 재실행됨)

**확인되지 않은 가정 (주의):**
- 과거 시점의 premium(할증율)이 오늘 시트 값과 동일했다고 가정하고 계산함. 실제로 그 사이 premium을 조정한 적이 있다면 해당 구간 백필 값은 부정확함.
- localStorage는 **브라우저/기기별로 별도 저장**됨. 여러 기기에서 접속해도 기록이 공유되지 않음.
