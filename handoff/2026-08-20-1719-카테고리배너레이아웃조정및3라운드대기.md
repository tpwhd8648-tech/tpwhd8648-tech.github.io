## 1. 목표

"무난함" 기준으로 확정하는 작업. 이전 handoff(`2026-08-20-1703`)에서 작업 방식을
"매 라운드 3개 시안 비교 → 반려 시 다음 라운드 3개 새로 생성" 방식으로 합의했고,
**이 문서는 그 이후 진행된 레이아웃 조정(여백/크기) 2건을 반영해 최신 상태로
갱신**한 것. **톤/패턴 결정은 여전히 미결 — 다음 세션은 2라운드(3/4/5안) 피드백부터
이어서 진행.**

### (2) 레이아웃 조정 — 이번 세션에서 완료, 이미 배포됨 (확인 완료)

톤 결정과 별개로, 사용자가 "히어로랑 카테고리 배너 사이에 공간이 없어서
답답해 보인다"고 지적 → 두 차례에 걸쳐 레이아웃만 수정(배경 톤/패턴은 A안
그대로 유지된 상태에서 진행):

**a) 여백/gap 추가** (커밋 `b2fa5bd`)
- `.category-banners`: `gap: 0` → `gap: 12px`, `padding: 40px 12px 0` 추가,
  `background: #fff` 추가 (히어로와 배너 사이 흰 여백 확보)

**b) 배너 높이 축소** (커밋 `db77cba`)
- `.cat-banner` 데스크톱: `height: 280px` → `220px`
- `.cat-banner` 모바일(`@media` 내부): `height: 180px` → `150px`
- 사유: 히어로(580px)와 배너의 비율 격차가 너무 커서 배너가 왜소하게
  눌려 보인다는 피드백

**현재 `assets/css/style.css`의 최종 값** (다음 세션이 3라운드 시안을 만들 때
이 값 기준으로 프리뷰를 맞출 것 — 이전 handoff의 프리뷰 HTML은 옛날 크기
기준이라 그대로 재사용하면 실제 사이트와 비율이 달라짐):
```css
.category-banners { display: grid; grid-template-columns: repeat(3, 1fr); gap: 12px; padding: 40px 12px 0; background: #fff; }
.cat-banner { position: relative; height: 220px; overflow: hidden; cursor: pointer; }
/* 모바일 (@media 쿼리 내부) */
.cat-banner { height: 150px; }
```

- 두 커밋 모두 Playwright로 데스크톱(1280px)·모바일(390px) 스크린샷 확인 완료
- `node --check` 문법 검증 완료, `inject-cache-busting.js` 2회 실행(2차 0건
  갱신)으로 정합성 확인 완료
- 두 커밋 모두 push 완료, `git ls-remote`로 원격 반영 확인 완료
