## 5. 참고 사항

- **백업 브랜치**: `backup-2026-07-21-2055` (origin/main 커밋 `6381539`
  기준, 이번 세션 브랜드 교체 작업 시작 직전 스냅샷). 원격 push 확인 완료.
  롤백 필요 시 이 브랜치로 `git reset --hard` 가능.
- **git identity 로컬 설정 주의**: 이번 세션에서 `git config user.email`을
  `deploy@onetroybullion.kr`로 바꿨는데, 이는 **이 컨테이너의 로컬 git
  config**라 다음 세션에서 레포를 새로 클론하면 초기화된다. 다음 세션
  시작 시 커밋 전에 `git config user.name "Claude Deploy" && git config
  user.email "deploy@onetroybullion.kr"`를 다시 설정할 것 (기존
  `deploy@midasbullion.kr`로 되돌아가지 않도록 주의).
- **생성기 스크립트 미실행 주의**: `scripts/generate-coin-pages.js`는
  Google Sheets gviz API를 호출하는데, 이 세션의 네트워크 허용
  도메인 목록에 Google Sheets 관련 도메인이 없어 직접 실행해서
  재생성 검증은 못 했음. 대신 템플릿 소스 코드 자체를 정적 치환
  방식과 동일하게 수정했으므로, 다음 GitHub Actions 정기 실행
  (nightly cron `generate-coin-pages.yml`) 때 자동으로 OneTroy
  Bullion 브랜드로 정상 생성될 것으로 예상(확인된 사실 아님 — 다음
  세션에서 Actions 실행 로그나 재생성된 파일로 검증 필요).
- **브랜드 표기 통일 기준**: 앞으로 새 파일/코드 추가 시 `OneTroy
  Bullion`(캐멀케이스) 표기를 기본으로 사용할 것. `Onetroy`(구
  표기, 붙여쓰기)나 `ONETROY`(전체 대문자)로 혼용하지 않도록 주의.
