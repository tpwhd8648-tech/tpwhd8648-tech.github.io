## 1. 목표

`index.html` 카테고리 배너(`.cat-gold`/`.cat-silver`/`.cat-collectible`) 배경
톤/패턴을 "무난함" 기준으로 확정하는 작업의 연속(4라운드 진행). 동시에
배너 안 코인 이미지가 위아래로 잘려 보이던 문제를 발견해 별도로 수정·배포함.

### (2) 4라운드 배너 톤 시안 — 진행 중, 전부 미확정 (확인 완료)

이전 세션(3라운드)에서 6안(보케 리파인)이 임시 적용된 상태로 시작.
사용자가 6안에 대해 "안 끌린다"는 반응 → 4라운드 진행:

**a) 1차 시도 — 9/10/11안 (완전히 반려)**
- 9안 헤어라인 텍스처, 10안 소프트 비네트, 11안 마이크로 도트
- 사용자 피드백: "다 똑같은 이미지 같다" → 코인이 배너 대부분을 가려
  배경 텍스처 차이가 거의 안 보이는 문제 확인, 투명도 강화판(9안/11안)
  재생성해서 재시도했으나 **여전히 "컨셉 자체가 비슷해서 의미 없다"고
  반려**

**b) 2차 시도 — 12/13/14안, 완전히 다른 컨셉 (반려)**
- 12안 다크 스포트라이트(짙은 배경+조명), 13안 워터마크 실루엣(골드바
  워터마크), 14안 듀오톤 대각선 스플릿(그래픽적 2톤 분할) — 색감까지
  자유롭게 바꿔 이전 시안들과 확실히 다르게 생성
- 사용자 피드백: "셋 다 안 끌린다" (구체적 이유는 "그냥"이라 별도
  없음) — 12번째 이후 시안까지 반복 반려되는 패턴 확인

**c) 3차 접근 — 방식 전환, 참고 사례 검색 + 미니멀 방향 (피드백 대기 중)**
- 패턴 계속 새로 만드는 방식 대신, (1) 해외 불리온 사이트(APMEX, JM
  Bullion 등) 실제 배너 참고 이미지 검색해서 공유, (2) 텍스처 없는
  미니멀 단색 배경 시안 생성하는 두 갈래로 진행하기로 사용자와 합의
- 미니멀 단색 3종 생성: **15안**(현재 톤 유지, 패턴만 제거), **16안**
  (어두운 톤), **17안**(밝은 톤 — 단, 흰 글자 대비 부족해 실제 채택 시
  글자색 조정 필요)
- **이 지점에서 사용자가 코인 잘림 문제로 화제 전환** → 15/16/17안에
  대한 사용자 피드백은 아직 받지 못함, **다음 세션 최우선 확인 필요**

### (3) 레이아웃 관련 참고 확인 사항 (완료)
