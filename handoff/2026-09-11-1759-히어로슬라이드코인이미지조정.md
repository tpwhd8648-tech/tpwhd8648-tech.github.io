## 1. 목표

직전 세션(`2026-09-11-1749`)에서 만든 2027 양띠 히어로 슬라이드의 코인 배치를
사용자 피드백에 따라 반복 조정하는 것. 최종적으로 앞면(양 디자인)+뒷면(찰스 3세
초상) 2개 코인만, 크게 + 살짝 겹치게 + 여백이 허전하지 않도록 배치하는 것으로
마무리함.

## 2. 현재 상태

**확인 완료 (이번 세션에서 거친 반복 과정, 최신이 최종본)**:
1. 앞/뒤 코인을 겹치지 않고 나란히 배치한 최초 버전 → 사용자가 "살짝 겹치게,
   앞면이 위로" 요청 → 겹침 적용
2. 사용자가 Perth Mint 공식 배너(금화+은화 2종 총 3개 코인이 부채꼴로 겹쳐
   화면을 꽉 채우는 참고 이미지)를 보여주며 "배너가 허전해 보인다, 이렇게 꽉 차게"
   요청 (단, 텍스트는 추가하지 말라고 명시) → 보유한 코인 이미지가 앞/뒤 2종뿔이라,
   앞면 이미지를 한 번 더 복제(어둡게 톤다운)해서 3개 코인 부채꼴 구성으로 확장,
   상하로 살짝 프레임 밖으로 베어나가게 처리해 밀도 있게 채움
3. 사용자가 "3번째 이미지는 없애줘, 앞/뒤만 남겨줘" 요청 → 복제본(3번째) 제거,
   단 허전함 피드백은 유효하므로 **앞/뒤 2개 코인 크기 자체는 3-코인 버전 때
   키운 크기(front_h≈H×1.04, mid_h≈H×0.96, 상하 살짝 베어나감)를 그대로 유지**한
   채 최종 확정
4. 최종 이미지를 `images/header-slide-goat-2027.jpg`에 반영, 커밋 `a7e0d3d`로
   push 완료 (`git fetch`로 직전 원격 커밋 `ff7b2a0`과 로컬 일치 확인 후 커밋 →
   push, 추가 리베이스 불필요했음). `git ls-remote`로 반영 확인.
5. PAT는 push 직후 plain HTTPS로 원복 완료.

**미확인**:
- 배포된 실제 사이트에서 최종 코인 배치(크기/겹침/상하 베어나감) 렌더링 확인

  화면에서는 코인 중심부가 크롭될 수 있음
- 사용자가 최종본에 만족했는지는 이번 메시지("이걸로 푸쉬해주고")로 볼 때

## 5. 참고 사항

- **커밋 이력**:
  - `ff7b2a0` — 직전 세션 종료 시점 (인수인계 문서 + 원격 병합)
  - `a7e0d3d` — 이번 세션: 코인 이미지 최종 조정(앞/뒤 2개, 확대+겹침 유지,
    3번째 복제 코인 제거)
  - `git ls-remote` 결과 원격 `main` 최신 커밋과 로컬 일치 확인함.
- **백업 브랜치**: 기존 이미지 파일 1개만 덮어쓰는 변경이라 별도 백업 브랜치는
  생성하지 않음. 최신 백업은 여전히 `backup-2026-08-20-1755`.
- **반복 조정 과정 기록 이유**: 이번 세션은 코인 배치를 4번 정도 다시 그렸는데
  (겹침 없음 → 살짝 겹침 → 3코인 확장 → 2코인 확정+확대 유지), 다음에 비슷한
  "허전하다/꽉 채워달라" 피드백이 오면 "코인 개수를 늘리기"보다 "기존 코인
  크기를 키우고 프레임 밖으로 살짝 베어나가게"하는 쪽이 최종 채택된 방향이었다는
  점을 참고할 것.
- **PAT 보안**: push 직후 `git remote set-url origin`으로 plain HTTPS 원복,
  `git remote -v`로 확인함. 토큰 값은 이 문서나 메모리에 저장하지 않음.
