## 3. 진행 단계 (재사용 가능 절차)

### 3-1. 상품 이미지를 신규 추가할 때 (2027 폴더가 처음인 경우)

1. sparse-checkout에 새 연도 폴더 추가 (최초 1회):
   ```
   git sparse-checkout set --no-cone '/*' '!/images' 'images/products/2026/*' 'images/products/2027/*'
   ```
2. 이미지를 1200×1200 정사각형·흰 배경으로 통일 (Pillow로 캔버스 중앙 배치 후 리사이즈).
3. 파일명 규칙: `{slug}.png`(앞면=대표 이미지), `{slug}-back.png`(뒷면).
4. `coin-data.js`의 `IMAGE_MAP`에 `coin-descriptions.js`와 동일한 keywords로 매핑 추가.
5. `node --check` → `inject-cache-busting.js` 2회 실행(2회차 0건 확인) → 커밋 → push.

### 3-2. 시트 등록 후 즉시 반영이 필요할 때 (예약 실행까지 기다리지 않고)

1. GitHub API로 workflow_dispatch 트리거:
   ```
   curl -X POST -H "Authorization: Bearer <PAT>" \
     -H "Accept: application/vnd.github+json" \
     https://api.github.com/repos/tpwhd8648-tech/tpwhd8648-tech.github.io/actions/workflows/generate-coin-pages.yml/dispatches \
     -d '{"ref":"main"}'
   ```
   204 응답이면 정상 접수.
2. `.../actions/workflows/generate-coin-pages.yml/runs?per_page=3`로 실행 상태 폴링
   (`status`가 `completed`, `conclusion`이 `success`일 때까지 대기).
3. 완료 후 `git pull origin main`으로 로컬에 자동 커밋된 결과 반영, 생성된
   `coins/coin-{slug}-{year}.html` 존재 여부와 내용(상품명/이미지 경로) 확인.
4. **주의**: 코드(`assets/js/*.js` 등) 변경 push는 워크플로우를 자동 트리거하므로
   수동 실행 불필요. 시트 데이터만 바뀐 경우(코드 변경 없음)에만 수동 트리거가
   의미 있음.
