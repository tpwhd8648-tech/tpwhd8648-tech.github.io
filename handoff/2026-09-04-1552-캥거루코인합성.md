# 캥거루 코인 합성 인수인계 문서

작성일: 2026-09-04

> **나중에 이 작업을 다시 찾을 때 검색 키워드**: "캥거루 코인 합성"
> (예: "캥거루 코인 합성했던 방식대로 이글도 해줘" / "캥거루 코인 합성 어떻게 했는지 찾아봐줘")

## 1. 목표

인덱스 페이지 히어로 슬라이더의 코인 이미지(사막/바위 등 연출 배경 위에 놓인 코인
사진)가 실제 판매 상품과 디자인이 다르거나(특히 캥거루) 오래된 렌더링이라, 배경과
코인 테두리는 그대로 두고 코인 "얼굴"(정면 디자인)만 실제 상품 사진
(`images/products/2026/{slug}.png`)으로 자연스럽게 합성 교체하는 것.
캥거루 슬라이드를 먼저 시범 적용해 방식을 검증했다.

## 2. 현재 상태

**확인 완료**:
- `images/header-slide-kangaroo.jpg`의 코인 얼굴을 `images/products/2026/kangaroo.png`
  (2026년 40주년 기념 디자인, 캥거루 2마리 + "40" 마크)로 교체 완료, 커밋 `31d0ba3`
  으로 푸시됨.
- 배경(울루루/사막/나무)과 코인 테두리(밀링 엣지)는 원본 그대로 유지.
- 결과물 크기(2436×625)가 원본과 동일함을 확인.
- 사용자에게 원본/새 버전 나란히 전달해 승인 받음 ("수정한게 더 좋다").

**미확인**:
- 실제 배포된 사이트(GitHub Pages)에서 최종 렌더링 확인 안 됨(로컬 합성 결과만
  확인).
- 완벽한 포토샵 수준 합성은 아님 — 원근/그림자는 근사치로 처리됨. 확대해서 보면
  약간의 이질감이 있을 수 있음.
- 나머지 3개 슬라이드(이글/버팔로/필하모닉)는 아직 적용 안 됨. 다만 캥거루가
  기존 디자인과 가장 다르다고 판단해 먼저 진행한 것이고, 나머지 3개는 기존 디자인이
  실제 상품과 이미 유사해 우선순위가 낮음(사용자 판단).

## 3. 진행 단계 (캥거루 코인 합성 절차 — 재사용 가능)

1. **좌표 파악(필수)**: 원본 히어로 이미지에서 코인이 있는 영역을 크롭한 뒤 50px
   격자 + 좌표 텍스트를 오버레이해서 그린다. `draw.ellipse`로 여러 번 시안을
   그려보며 코인 "얼굴"(테두리 밀링 라인 제외, 안쪽 디자인 영역)의 타원 중심·반지름을
   육안으로 맞춘다. 슬라이드마다 코인 각도/위치가 다르므로 매번 새로 잡아야 함.
2. **알파 컷아웃(필수)**: 상품 이미지(흰 배경)에서 코인만 알파 채널로 분리.
   흰색으로부터의 유클리드 거리 기준(`low=8, high=40` 선형 보간) — 기존 배너
   흰배경 제거 원칙과 동일한 방식 재사용.
3. **색보정 게인 계산(필수)**: 원본 코인 얼굴 중앙 패치와 상품 이미지 코인 중앙
   패치의 평균 RGB를 각각 샘플링, 채널별 게인(원본/상품)을 계산해 상품 이미지에
   곱한다. 배경 조명 톤(골든아워 등)에 맞추기 위함.
4. **리사이즈 + 블러(필수)**: 알파 컷아웃을 1번에서 잡은 타원 크기로 리사이즈
   (가로세로 비율을 다르게 주면 살짝 기울어진 느낌이 자연스럽게 재현됨). 색보정
   적용 후 `GaussianBlur(0.6)`로 살짝 부드럽게.
5. **페더링(필수)**: 알파 채널에 `GaussianBlur(1.2)` 정도를 줘서 기존 테두리와
   경계가 자연스럽게 섞이게 함.
6. **합성(필수)**: `alpha_composite`로 원본 배경 위에 합성. 결과물 크기가 원본과
   동일한지 반드시 확인.
7. **사용자 확인용 전달(필수)**: 완료 후 **반드시 `/mnt/user-data/outputs`에 원본과
   새 버전을 둘 다 복사해서 `present_files`로 전달**할 것. `view` 도구 결과는
   Claude만 볼 수 있고 사용자 화면에는 안 보임 — 이번 세션에서 실제로 이 실수가
   발생해 "안보이는데" 피드백을 받았음.
8. **승인 후 반영(필수)**: 사용자 승인 받으면 해당 `images/header-slide-*.jpg`
   경로에 덮어쓰기 → `git add --sparse images/...` → 커밋 → push.

## 5. 참고 사항

- **재사용 절차 문서화 방식에 대한 결정**: 캥거루 코인 합성 절차를 별도 파일
  (`docs/hero-coin-compositing.md`)로 빼는 방안과 `PROJECT_INSTRUCTIONS.md`에
  직접 넣는 방안을 검토했으나, 둘 다 채택하지 않고 **이 핸드오프 문서(3번 섹션)에만
  남기기로 결정**했다. 이유: `PROJECT_INSTRUCTIONS.md`는 매 세션 전체가 로딩되므로
  분량을 늘리고 싶지 않았고, 필요할 때 "캥거루 코인 합성"이라는 키워드로 handoff
  폴더를 검색해서 찾는 방식이면 충분하다고 판단함.
- **찾는 방법**: 이 문서가 3개 최신 핸드오프 범위 밖으로 밀려난 뒤에는 자동으로
  로딩되지 않으므로, 사용자가 "캥거루 코인 합성했던 방식대로 해줘" 등으로 명시적으로
  언급해야 Claude가 `handoff/` 폴더를 검색해서 이 문서를 찾아 절차를 재사용할 수 있다.
- 백업 브랜치: 이번 세션은 이미지 파일 1개 교체(되돌리기 쉬움)라 별도 백업 브랜치는
