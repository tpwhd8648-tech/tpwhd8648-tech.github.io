### (2) favicon.ico 신규 제작 (검증 완료 — 커밋 `5a0a709`, 다른 세션 작업)

- `favicon.svg` 확인: 옛 Midas 'M' 아이콘 → OneTroy 금색 꽃잎 모티프로 교체

- 전체 HTML 30개 파일 중 `favicon.ico` 링크 누락 1건(`naver...html`)은
  네이버 사이트 소유 확인용 파일이라 정상(favicon 불필요).
- 이후 신설된 `pages/faq.html`에도 favicon.ico 링크 이미 포함되어 누락 없음.
- 종결 처리.

### (3) GA4 측정 ID 발급 (미완료 — 진행 중, 다음 세션에서 이어감)

- 발급 절차(analytics.google.com → 속성 생성 → 웹 데이터 스트림 생성 →
  `G-XXXXXXXXXX` 측정 ID 확인)를 사용자에게 안내함.
- 사용자가 접속 시도했으나 `DNS_PROBE_FINISHED_NXDOMAIN` 오류 발생 →
  확인 결과 다른 사이트는 정상 접속되고 이 도메인만 실패, 원인은 사용자
  기기에 설치된 **애드가드(AdGuard)의 트래커 차단 기능**으로 추정(analytics
  도메인 특성상 광고/트래커 차단 앱이 흔히 차단함).
- 애드가드 예외 처리 대신 **다른 기기에서 진행하기로 결정** — 아직 측정
  ID는 발급받지 못한 상태로 세션 종료.
- 코드 반영(`nav.js`에 gtag.js 스니펫 삽입)은 측정 ID를 받는 즉시 가능,
  아직 미착수.

## 3. 진행 단계

1. (필수) 사용자가 다른 기기(애드가드 미설치 기기 또는 PC)에서
   analytics.google.com 접속 → 속성 생성 → 웹 데이터 스트림 생성
   (URL: `https://tpwhd8648-tech.github.io`) → 측정 ID(`G-XXXXXXXXXX`) 확인.
2. (필수) 다음 세션 채팅에 측정 ID 전달.
3. (필수) `assets/js/nav.js`(전 페이지 공통 로드)에 gtag.js 스니펫 추가:
   ```html
   <script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
   <script>
     window.dataLayer = window.dataLayer || [];
     function gtag(){dataLayer.push(arguments);}
     gtag('js', new Date());
     gtag('config', 'G-XXXXXXXXXX');
   </script>
   ```
4. (선택) 애드가드가 원인이 맞는지 나중에 확인하고 싶다면, 애드가드 앱에서
   `analytics.google.com`을 예외 목록에 추가 후 재접속 테스트 — 급하지 않음.
