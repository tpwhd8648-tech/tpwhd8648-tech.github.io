## 1. 목표

지난 세션에서 완료된 브랜드명 교체(OneTroy Bullion) 이후 남아있던 시각적 결함(로고

## 2. 현재 상태

### (1) 로고 텍스트 accent 크기 불균일 수정 (확인 완료 — 커밋 `a0e7e2b`, push 완료)

- 사용자가 스크린샷으로 제보: 헤더 로고 "ONETROY BULLION" 텍스트가 삐뚤빼뚤하게
  보임.
- 원인 확인: `assets/js/nav.js`의 `.logo-brand .accent` 규칙이 O/T/B 세 글자만
  `font-size:1.18em`으로 키우고 있었음. `text-transform:uppercase`로 전체가
  대문자로 표시되는 상태에서 특정 글자만 커서 줄이 고르지 않게 보인 것.
- 조치: `font-size:1.18em` → `1em`으로 변경, 전체 글자 크기 통일.
- 검증: `node --check assets/js/nav.js` 통과.

### (2) 사업자 정보(대표자명/임시 주소/전화번호) 반영 (확인 완료 — 커밋 `143c0c3`, push 완료)

- 사용자가 제공한 확정 정보: 대표자 **정세종**, 전화번호 **010-3737-5757**.
- 정식 주소는 아직 미확정 — 사용자 요청에 따라 **종로3가역 인근 임시 주소**로
  우선 표기(`서울특별시 종로구 종로3가 10-5`, 나무위키에서 종로3가역 1호선
  출입구 지번 확인 후 채택. 정확한 사업장 주소가 아니라 "역 주변"이라는
  임시 표기임을 명확히 인지할 것).
- **통신판매업신고번호는 사용자가 "아직 신청 안 했다"고 확인** — 반영하지
  않고 To-Do로 유지.
- 변경 파일 2개:
  - `assets/js/footer.js`: 하단 카피라이트 줄에 대표자명 추가, 사업자등록번호/
    임시주소/전화번호 줄 추가, "오시는 길" location-grid 박스 주석 해제 후
    임시 정보로 채움, footer의 "오시는 길" 링크를 `#contact-map` 앵커로 복원.
  - `pages/contact.html`: PHONE 정보 카드 주석 해제(010-3737-5757 반영,

    교체, Google Maps iframe도 "종로3가역" 검색 임베드로 교체 — 기존 임베드는
    무관한 좌표였음).
- 검증: `node --check`(footer.js), Python으로 contact.html의 JSON-LD `json.loads()`
  파싱 성공, HTML 주석 태그(`<!--`/`-->`) 개수 일치 확인.

## 5. 참고 사항

- **이번 세션은 백업 브랜치 없음** — 변경 범위가 파일 3개, 되돌리기 쉬운
  수준의 텍스트/속성 수정이라 3-1 절차(다중 파일 고위험 작업) 대상 아님으로
  판단함.
- **임시 주소의 출처**: "종로3가 10-5"는 실제 사업장 주소가 아니라, 종로3가역
  1호선 출입구의 지번(나무위키 검색으로 확인)을 "역 근처"라는 의미로 임시
  채택한 것. 정식 사업장 주소가 아니므로 반드시 정식 주소 확정 시 교체할 것 —
  전자상거래법상 표시 주소 요건과 무관한 placeholder임을 다음 세션이 착각하지
  않도록 주의.
- **지도 iframe 방식 변경**: 기존에는 `google.com/maps/embed?pb=...` 형태의
  좌표 기반 임베드(API 키 불필요하지만 좌표를 직접 알아야 함)를 썼으나, 이번엔
  `google.com/maps?q=검색어&output=embed` 형태(검색어 기반, 좌표 몰라도 됨)로
  교체함. 정식 주소 확정 시에도 이 방식을 유지하면 좌표 계산 없이 주소 텍스트만
  바꿔도 됨 — 예: `q=서울특별시+종로구+실제주소&output=embed`.
- **오늘 세션 시작 시 발견된 특이사항**: `assets/js/footer.js`에 이미
  "사업자등록번호 898-26-02365, 실제 상호는 골든민트, OneTroy Bullion 병기"
  내용이 반영돼 있었는데, 이 결정이 어느 세션에서 이뤄졌는지 핸드오프 문서에
  기록이 없었음. 이번 세션에서 그 위에 대표자명/주소/전화번호를 추가로 얹은
  것이므로, 향후 "골든민트 병기" 결정의 배경이 궁금하면 사용자에게 직접
  확인이 필요할 수 있음.
