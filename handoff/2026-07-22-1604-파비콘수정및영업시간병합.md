## 5. 참고 사항

- **백업 브랜치 없음** — 파비콘 수정은 파일 1개, 되돌리기 쉬운 수준이라
  3-1 절차 대상 아님.
- **검은 배경 원인은 추정임을 재확인**: SVG/PNG 자체 데이터는 완전 투명이었고,
  탭에서 보이던 검은 사각형은 브라우저(모바일 탭 UI)가 투명 파비콘에 씌우는
  것으로 추정해 흰 배경을 코드에 직접 넣는 방식으로 "우회 해결"함. 만약
  다음에도 특정 브라우저/다크모드에서 다르게 보인다는 리포트가 오면, 이
  가정 자체를 재검토할 것.
- **cairosvg 사용법 (다음에 참고)**: 이 세션 컨테이너에 `pip install
  cairosvg --break-system-packages`로 설치, `cairosvg.svg2png(url=..., 
  write_to=..., output_width=, output_height=)`로 SVG data URI를 원하는
  해상도의 PNG로 직접 렌더링 가능 — 로고/파비콘처럼 SVG 소스가 있는 그래픽을
  PNG로 재추출해야 할 때 유용함.
- **병합 시 주의**: 이번 세션처럼 로컬에서 커밋 후 push하기 전에 원격에
  새 커밋이 쌓여 있으면 `git merge origin/main --no-edit` 사용(리베이스
  아님, 기존 원칙 유지). 이번엔 병합 커밋 시 로컬 git identity가 처음에
  설정 안 돼 있어 "Committer identity unknown" 에러가 났음 — `git config
  user.name`/`user.email`을 커밋 전에 먼저 설정해둬야 병합 커밋도 문제없이
  됨 (이전에는 `-c` 플래그로 단발성 지정했으나, merge commit에는 리포지토리
  git config 자체가 필요함).
- **한글 전면 표기 논의 원문 요지**: Troy(트로이온스) 네이밍 의미가 영문에서만
  드러남 / 해외 귀금속 브랜드 영문 표기 관행 / 현재 영문 로고+한글 구어체
  병기가 절충안 / 전면 교체 시 27개 파일 규모 고위험 작업. 사용자가 "알겠어"로
  답했으나 이것이 "제안 수용(보류 유지)"인지 "제안 자체에 대한 단순 인지
  응답"인지는 확실하지 않음 — 다음 세션에서 필요시 재확인.
