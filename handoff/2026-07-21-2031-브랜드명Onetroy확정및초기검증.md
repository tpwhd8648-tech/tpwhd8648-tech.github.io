# 브랜드명 Onetroy 확정 및 초기 검증 인수인계 문서

작성일: 2026-07-21 (KST)

## 1. 목표

장기 보류 중이던 브랜드 리네이밍 To-Do를 재개해, 다수의 후보군을 검토한 끝에
신규 브랜드명을 **"Onetroy Bullion"**으로 확정하고, Kipris 상표 검색·도메인
확인을 통해 1차 실현 가능성을 점검함.

## 2. 현재 상태

### (1) 브랜드명 확정: Onetroy Bullion

- 기존에 검토하던 26개 후보군(Cabinet, Trove, Meridian, Beacon 등 아카이브/
  즉시성/프레스티지 계열)은 이번 세션에서 전부 후순위로 밀림.
- "Troy"(트로이온스, 귀금속 계량 국제 표준 단위) 컨셉을 살린 혼성어 계열
  (Onetroy, Troyon, Troyum, Truetroy, Troya 등)을 새로 브레인스토밍하고
  발음/의미/차별성/청결도(4항목, 각 5점) 기준 점수표로 비교.
- **Onetroy가 전 라운드에서 합계 1위(16점)** — "1트로이온스"라는 의미
  정확성이 핵심 근거. 사용자가 최종 확정.
- 네이밍 구조 원칙("Bullion + 단어")에 따라 **Onetroy Bullion**으로 확정.

### (2) Kipris 상표 검토 (확인 완료 — 수동 검색, 사용자 직접 수행)

- "ONETROY", "원트로이" 상표 검색 → **국내 결과 0건** (완전/부분일치
  기준 선행 상표 없음).
- "TROY", "트로이" 단독으로는 다수 결과(492건/2,858건)가 나오나 대부분
  무관 카테고리. 14류(귀금속)로 좁힌 결과 중 관련 있는 건 3건:
  - `TROY'A` — **거절** (2001 출원/2002 거절). 거절 사유: 선등록상표
    `TROYES`(등록번호 227542, 주식회사쌍방울)와 칭호·외관 유사 판단
    (상표법 제7조 제1항 제7호).
  - `BULUT TROYA JEWELRY` — **등록** (Troy가 다른 단어와 결합된 복합어라
    식별력 인정된 것으로 추정).
  - `RINGSTROY` — **포기** (심사 결과 아닌 자진 취하로 추정, 참고 가치 낮음).
- 문제가 됐던 선등록상표 `TROYES`(227542) 자체를 재검색 → **3건 모두
  "소멸" 상태 확인** (등록번호로 직접 검색은 특허 DB와 섞여 실패, 상표명
  "TROYES"로 검색해 확인 성공).
- **종합 판단(추정)**: 14류 내 Onetroy와 직접 충돌하는 살아있는 선행
  상표는 현재까지 발견되지 않음. 다만 "Troy 단독/짧은 형태는 거절 전례
  있음, 결합어는 등록 전례 있음"이라는 심사 경향 자체는 참고할 리스크로
  남아있고, 이는 수동 검색 기반 추정이라 **정식 선행상표조사(변리사)
  전까지는 확정 아님**.

### (3) 도메인 확인 (확인 완료 — Gabia, 사용자 직접 수행)

- `onetroybullion.com` — ✅ 등록 가능
- `onetroybullion.co.kr` — ✅ 등록 가능
- `onetroy.com` — ❌ 이미 등록됨. Whois 조회 결과 GoDaddy 프라이버시
  보호(Domains By Proxy) 적용으로 소유자 신원 비공개. 2017년 등록,
  2029년까지 갱신. 실제 접속 확인 결과 **GoDaddy 파킹 페이지**(운영 중인
  사업 없음, 도메인 판매 유도 페이지)로 확인됨 — 우리 브랜드와 무관,
  대응 불필요로 판단.

## 5. 참고 사항

- **이번 세션은 백업 브랜치 없음.** 코드 변경이 전혀 없었기 때문 (3-1
  절차 대상 아님).
- **"Standard Bullion" 후보는 국내 전용 운영 기준으로는 완전 배제 사유는
  아님**으로 재평가됨 — 동종업계 미국 실존 법인(Bullion Standard, Inc.,
  2010년 설립)과 이름이 겹치지만, Kipris 등록 자체를 막을 만큼 국내에
  알려진 상표는 아닐 가능성이 높음. 다만 우선순위는 낮게 유지, 이번
  세션에서 최종 결정은 Onetroy로 감.
- **Onetroy는 "완전 신조어"가 아니라 "One + Troy" 혼성어**라는 점을
  명확히 인지할 것. "Troy" 부분이 업계 표준 계량단위 용어에서 왔기
  때문에, 다음 세션에서 재논의 시 "이미 검증된 완전 안전한 이름"으로
  오인하지 말 것 — 정식 선행상표조사 전까지는 추정 판단 단계임.
- **Kipris 상표 검색 UI 사용법 (다음에 참고)**:
  - 특허·실용신안 탭이 기본 선택되어 있어 처음엔 상표 탭으로 바꿔야 함.
  - 필터 패널(슬라이더 아이콘) 안에는 "권리구분/유형/행정상태"만 있고
    **상품분류(류) 필터는 없음** — 대신 "결과 분류통계"(그래프 아이콘)
    버튼을 눌러 도넛 차트에서 류별 건수를 확인해야 함.
  - 등록번호로 직접 검색하면 다른 필드에 그 숫자가 우연히 포함된 무관한
    특허/상표까지 섞여 나오는 경우가 있음 — 등록번호보다 상표명 텍스트로
    검색하는 게 더 정확함.
- **TROY'A 거절 이유서에 인용된 지정상품**(귀걸이, 목걸이, 반지, 팔찌 등)이
  실제 상품분류 표기(25류)와 다르게 나온 것은 2002년 당시 구 분류체계와
  현재 니스분류 표기 차이로 추정 — 완전히 확인된 사실은 아니므로 다음
  세션에서 필요시 재검토.
