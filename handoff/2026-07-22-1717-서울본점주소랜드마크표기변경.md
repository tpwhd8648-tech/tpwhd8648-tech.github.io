## 5. 참고 사항

- **백업 브랜치 없음** — 변경 범위가 파일 2개, 텍스트/속성 수정 수준이라
  3-1 절차(다중 파일 고위험 작업) 대상 아님으로 판단.
- **낙원상가 선택 근거**: 종로3가역 인근에서 실존하는 대형 랜드마크 건물을
  찾기 위해 웹 검색으로 확인 — 1969년 완공된 15층 주상복합 건물, 악기
  전문상가로 유명, 종로3가역 도보 4분. 도로명 주소는 "서울특별시 종로구
  삼일대로 428", 지번은 "낙원동 288"(자료마다 284-6/288 등 약간 차이가
  있어 도로명 주소 기준으로 채택).
- **"임시"/"인근" 표현 제거의 의미**: 사용자 요청에 따라 화면에 보이는
  텍스트에서만 제거한 것이며, 실제 사업장 주소가 확정된 것은 아님.
  다음 세션에서 "주소가 이미 확정됐다"고 오인하지 않도록 주의 — 위
  To-Do의 "정식 사업장 주소 확정" 항목은 여전히 미해결 상태로 유지함.
  코드 주석에는 이 사실을 명시해뒀음.
- **지도 iframe 방식**: `google.com/maps?q=검색어&output=embed` 형태
  유지, 검색어만 `종로3가역`(지역명, 넓은 범위) → `낙원상가`(구체적
  건물명)로 변경해 지도 핀이 건물 하나를 명확히 가리키도록 함. 정식
  주소 확정 시에도 이 방식을 유지하면 좌표 계산 없이 검색어만 바꾸면 됨.
- **push 시 원격 경합이 반복되는 중**: 최근 세션들에서 로컬 작업 중
  다른 세션이 병렬로 `main`에 push하는 경우가 잦아지고 있음(이번
  세션에서도 2회 병합 발생). push 직전에는 항상 `git fetch` +
  `git merge origin/main --no-edit`로 최신 상태를 반영한 뒤 push할 것
  (기존 원칙 유지, 리베이스 아님).
